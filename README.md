## О проекте

Одностраничный сайт-портфолио студента первого курса. На сайте представлены краткая информация об авторе, изучаемые навыки, первый учебный проект и ссылка на GitHub. Портфолио можно постепенно дополнять новыми работами по программированию и анализу данных.

## Технологии

- HTML5 — структура и содержание страниц;
- CSS3 — оформление, адаптивная вёрстка и светлая/тёмная тема;
- JavaScript — интерактивное переключение темы;
- Git и GitHub — контроль версий и публикация проекта.

## Запуск

Откройте файл `index.html` в браузере. Дополнительная установка не требуется.
